# micronaut-inject sample ownership

[English](README.md) | [简体中文](README.zh-CN.md)

This module supplies bean and scope runtime APIs. The runnable scenario is owned by [di](https://github.com/normlanguage/di/tree/main/samples) in its `samples/` directory; use that example to observe the behavior through the public API.

The module identity and pinned dependencies are defined in [module.norm](../micronaut/inject/module.norm).
