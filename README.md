# Micronaut Inject

[English](README.md) | [简体中文](README.zh-CN.md)

The adapter declaration and runnable example are in `micronaut/inject`. It pins Micronaut Inject 5.1.13 and defines its package coordinates in [module.norm](micronaut/inject/module.norm). The public API covers Beans, scopes, factories, conditions, replacements, and configuration annotations.
